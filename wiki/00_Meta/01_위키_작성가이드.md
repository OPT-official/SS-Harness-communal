# 01_위키 작성 가이드

위키 문서를 쓸 때의 문체·형식·구조 규칙. 넘버링/파일명은 `02_네이밍_넘버링_규칙.md`가 담당하고,
여기서는 **문서 내부를 어떻게 쓰는지**를 다룬다.

## 1. 문서의 기본 골격

모든 문서는 이 순서를 권장한다.

```markdown
# [제목]

> (선택) 한 줄 요약 — 이 문서가 무엇인지 / 누가 언제 보는지

## 1. …
## 2. …
```

- **맨 위 제목은 `#` 하나**, 파일당 1개.
- 긴 문서는 첫머리에 **한 줄 요약(blockquote `>`)** 을 둔다.
- 섹션이 3개 이상이면 번호를 매긴다(`## 1.`, `## 2.`).

## 2. 문체

- **결론 먼저, 근거 나중.** 읽는 사람이 스캔으로 답을 찾을 수 있게.
- 문장은 짧게. 한 문장에 한 가지.
- 신입도 읽는다는 전제 — 약어는 처음 나올 때 풀어 쓰고, 필요하면 `20_Curriculum_공통/90_용어사전`에 등재.
- 추측/미확인 정보는 그렇게 **표시**한다: `[추론]`, `[가설]`, `[미확인]`, `[외부출처]`.
  사실처럼 단정하지 않는다.

## 3. 마크다운 규칙

| 요소 | 규칙 |
|------|------|
| 제목 | `#`=문서 제목(1개), `##`=대섹션, `###`=소섹션. 4단계 이상 지양 |
| 목록 | 순서 있으면 `1.`, 없으면 `-` |
| 표 | 비교·정리는 표로. 헤더 행 필수 |
| 코드 | 명령어·경로·파일명은 백틱. 여러 줄은 ```` ``` ```` 펜스 + 언어 표기 |
| 강조 | 정말 중요한 것만 **굵게**. 남발 금지 |
| 링크 | 위키 내부 문서는 상대경로로 링크 |

## 4. 표기 통일

- **경로/폴더/파일명**: 백틱. 예) `60_기수별활동/1기_2026여름/`
- **날짜**: `YYYY-MM-DD`(본문 서술) / `YYYYMMDD`(파일명 끝).
- **기수 표기**: `N기_YYYY계절` (예: `1기_2026여름`).
- **용어**: 한국어 우선, 필요 시 괄호로 원어 병기. 예) 기준 정보(Master Data).

## 5. 이미지·첨부

- 이미지는 해당 문서 옆 `assets/` 폴더에 넣고 상대경로로 참조.
- 대용량 원본(zip, 대형 xlsx 등)은 위키에 직접 올리지 않는다 — 링크/외부 저장 후 위치만 기록.
